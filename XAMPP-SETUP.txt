ANOTHER COMPUTER / FRESH DOWNLOAD
1. Install XAMPP with PHP 8.2+ and enable/start Apache and MySQL.
2. For a GitHub source download, run composer install --no-dev.
   The full prototype ZIP already includes vendor dependencies.
3. In phpMyAdmin, create smartbiz_hub_laravel with utf8mb4_unicode_ci collation.
4. Copy .env.example to .env, then enter your own database username/password.
5. Run php artisan key:generate and php artisan migrate --seed.
   Do not seed over records you need; this is for a fresh demonstration database.
6. Add the following to XAMPP apache/conf/extra/httpd-vhosts.conf, replacing
   C:/path/to/project with the actual extracted project directory:

Listen 127.0.0.1:8081
<VirtualHost 127.0.0.1:8081>
    ServerName localhost
    DocumentRoot "C:/path/to/project/public"
    <Directory "C:/path/to/project/public">
        Options -Indexes +FollowSymLinks
        AllowOverride All
        Require local
    </Directory>
</VirtualHost>

7. Run C:\xampp\apache\bin\httpd.exe -t. If Syntax OK, restart Apache.
8. Open http://127.0.0.1:8081.

If PHP is not on PATH, use C:\xampp\php\php.exe instead of php.
Do not point Apache at the project root: it must serve public/ only.
The download excludes live records, .env and the former SQLite database.
Demo seeding supplies fictional accounts and transactions for a fresh installation.
